# Task-specific supplier-screening Skill

Organize this repeatable task as four passes:
1. Index source IDs and quotation revisions; retain explicit missing/conflict data.
2. Apply exact policy gates with decimal calculations before semantic comparisons.
3. Evaluate independent references only for records that still require that judgment.
4. Account for every vendor, preserve partial results, sort eligible vendors, validate
   the final schema and approval flag. Use helpers.py and your own scripts as useful.

TASK.md remains authoritative. This procedure contains neither labels nor a runner.
